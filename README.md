# Crypto Analysis Project

AI-powered cryptocurrency market analysis platform for a Software Engineering 
final project. The system collects real market data, computes technical 
indicators, generates BUY/HOLD/SELL signals using a machine learning model, 
and evaluates strategies through backtesting — presented via a web dashboard.

**Note:** This project analyzes and simulates trading strategies for 
educational purposes. It does not execute real trades or handle real funds.

## Architecture

Real Crypto Data (Binance / CoinGecko)
↓
Data Collection & Database
↓
Data Processing + Technical Indicators
↓
Machine Learning Model
↓
BUY / HOLD / SELL Signal
↓
Backtesting / Strategy Simulation
↓
Web Dashboard
↓
Cloud Deployment
